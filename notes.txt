Migration:
    Migration changes the database structure. CRUD changes/uses the data inside that structure
cmd for migration after changing design in schema.prisma:
    pnpm exec prisma migrate dev --name add_user_auth
    What Prisma did:
            schema.prisma
                ↓
            defines database structure
                ↓
            migration
                ↓
            updates PostgreSQL structure
                ↓
            seed
                ↓
            puts initial data into tables
                ↓
            application
                ↓
            CRUD operations on that data
