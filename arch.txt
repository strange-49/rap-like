Backend:
server.ts → starts the Node.js server.
app.ts → sets up the backend application.
routes/ → place where our API endpoints will live.
health.routes.ts → basic /health and /ready endpoints to check whether the server is alive/ready.
common/errors/ → standard way to handle backend errors.
common/logging/ → logging setup.
common/middleware/ → reusable request-processing logic.
common/validation/ → place for request validation infrastructure.
config/ → handles environment/configuration.
modules/ → empty for now; later we'll put Customer, Rider, Ride, Payment, etc. modules here.
realtime/ → empty for now; later WebSockets.
tests/ → reserved for backend tests.
